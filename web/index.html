Equipment only. Each attached ID is a 10-bit field (0–1023). Blank preserves it; 0 removes it. Element changes append crystals to unused upgrade slots and raise the item level; existing attachments are never removed automatically.

Attachment edits need in-game testing. Special material effects and bonuses are calculated by the game on load.
